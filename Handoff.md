# Handoff: galaxy portfolio redesign

Last updated 2026-11-03. Read `DESIGN.md` first; it is the full spec. This file covers where the work stopped.

## Where things are
- **Prototype:** `index.html` (single file, vanilla canvas JS). It is a universe of 14 galaxies (13 projects and experiences, plus the black hole of unfinished projects), with three zoom levels (universe, galaxy, solar system), semantic search, hover previews and a breadcrumb.
- **Animations:** each galaxy's animation is a plugin in `anims/<key>.js`; the API is in `anims/README.md`. Plugins take the galaxy's live star positions (`api.stars()`) and can dim the spiral (`spiralDim`), so animations are made of the galaxy's own stars. `api.lightBoost()` (one line at the top of a plugin) gives the light theme a little more weight; dark is untouched.
- **Embeddings:** `embeddings.js` is generated by `tools/embed.py` (BAAI/bge-small-en-v1.5 via fastembed, mean-centred, PCA, int8). It gives chunk positions, the galaxy-to-galaxy cosines and the search vectors. Search embeds a fixed vocabulary offline, so the page needs no runtime model. Regenerate after editing CHUNKS or META: `%TEMP%\embed-venv\Scripts\python.exe tools/embed.py` (venv: `python -m venv` + `pip install fastembed`). Check search quality with `node tools/search-eval.cjs` (13 gold queries; exits 1 on failure).
- **Hover previews:** League (live page, screenshot until it loads), Minecraft (`img/minecraft.mp4`, a 10 s timelapse cut from the AI-Builder-Minecraft README demo), Sinai and SenseWay logos.

## How to run and test
See `TESTING.md`. In short: `python -m http.server 8000` from the repo root, open `http://localhost:8000/`; `?open=<key>&dtmax=0.7` flies straight into a galaxy and lets time advance in throttled automated Chrome. Console helpers: `__galaxy.open(key)`, `__galaxy.close()`, `__galaxy.enterSun(i)`.

## User preferences learned
- Keep solutions simple; don't overengineer.
- "Use subagents" means the delegate skill (Codex/agy). Claude subagents only when named (e.g. "Sonnet agents").
- The user is direct and visual. Show working prototypes rather than describing ideas, and confirm behaviour in a real browser before reporting success.
